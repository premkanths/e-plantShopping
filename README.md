# Paradise Nursery - A Modern Houseplant E-Commerce Store

Welcome to **Paradise Nursery**, a beautiful online plant store application designed to bring green companions into your life. This application is built with **React**, **Redux Toolkit**, and modern CSS.

## Features
- **Responsive Landing Page:** Welcoming interface with a high-quality background and a "Get Started" button.
- **Product Catalog:** Houseplants categorized into groups (Air Purifying, Aromatic, and Low Maintenance). Each card details a plant's name, price, description, and contains an "Add to Cart" action.
- **Redux-Powered Shopping Cart:** Adjust quantities (+/-), see real-time subtotal calculations, remove items, and see the total price updating immediately.
- **State Management:** Fully managed by Redux Toolkit for clean actions (`addItem`, `removeItem`, `updateQuantity`).
